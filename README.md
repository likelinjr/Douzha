# Environment Variable Template
Create .env file in the project root directory. The content is same as .env.bak

# Working Directory
The project uses `Doza` as the workspace:
- **Root**: `Doza/`
- **Read/Write**: `Doza/Workspace/`
- **Read-only**: Documents, Music, Downloads and other folders in `Doza`

# Sikll Directory
You can download "skills" and place it in the "src/skills/Skills" directory. The system will then load these skills.
