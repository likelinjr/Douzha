# Environment Variable Template
Create an.env file in the project root directory. The content is as follows:
```env
ACTIVE_MODEL=
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL_NAME=deepseek-reasoner

GOOGLE_API_KEY=
GOOGLE_MODEL_NAME=gemma-4-31b-it
# gemini-3.1-flash-lite-preview

ZHIPU_API_KEY=
ZHIPU_MODEL_NAME = glm-4.5-air
# glm-4.6v 

HTTPS_PROXY = http://127.0.0.1:7897
HTTP_PROXY = http://127.0.0.1:7897 

TAVILY_API_KEY= tavily api key
WEATHER_API_KEY = Fengyun Weather API Key
```
